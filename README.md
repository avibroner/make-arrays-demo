# make-arrays-demo

נתוני דמו לתרגול מערכים וקולקשנים ב-Make: 50 משימות לדוגמה (נתונים בדויים, ללא מידע אמיתי).

כתובת לשימוש במודול HTTP > Make a request (GET, Parse response = Yes):

https://avibroner.github.io/make-arrays-demo/tasks.json

המערך נמצא תחת `tasks`. בכל פריט: `id`, `subject`, `description`, `due_date`, וקולקשן מקונן `details` עם `status`, `priority`, `type`.
